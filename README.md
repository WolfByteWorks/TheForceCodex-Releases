# The Force Codex for Mac

Update feed and downloads for The Force Codex, a checklist of Star Wars novels and comics by WolfByte.Works.

Download the latest Mac version from [Releases](https://github.com/WolfByteWorks/TheForceCodex-Releases/releases/latest). The app updates itself through `appcast.xml`.

Requires an Apple silicon Mac with macOS 14 or later.
